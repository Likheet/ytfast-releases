# YTFast downloads

Downloads for [YTFast](https://ytmfast.com), a native desktop app for YouTube Music on Windows and Mac.

Get the latest version from **[ytmfast.com/download](https://ytmfast.com/download)**, or from [the latest release](../../releases/latest).

- **Windows** (64-bit, Intel or AMD): `YTFast-for-Windows.zip`
- **Mac** (Apple Silicon, M1 or newer): `YTFast-for-Mac.zip`

YTFast is free for 14 days, then US$4 once. See [pricing](https://ytmfast.com/pricing). This repository holds release files only.
