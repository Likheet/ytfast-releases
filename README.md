# YTFast downloads (archived)

This repository is archived. **Download YTFast from the [YTFast releases page](https://github.com/Likheet/YTFast/releases/latest).**

YTFast is a native desktop app for YouTube Music on Windows and Mac. The files here are old versions, up to v0.5.0. They stay here only so that old links keep working.

YTFast is an independent project, not affiliated with or endorsed by Google LLC or YouTube.
